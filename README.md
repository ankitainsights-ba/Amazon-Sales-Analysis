# Amazon Sales Analysis Dashboard

## Project Overview
This project analyzes Amazon sales data using Microsoft Power BI.

## Objective
To understand sales performance, revenue trends, and product performance through interactive visualizations.

## Tools Used
- Power BI
- Power Query
- DAX
- Excel

## Key Activities
- Data Cleaning
- Data Transformation
- Data Analysis
- KPI Development
- Dashboard Creation

## Business Insights
- Identified top-performing products.
- Analyzed revenue performance.
- Evaluated product category performance.
- Identified opportunities for business improvement.

## Conclusion
The project demonstrates how Power BI can transform raw sales data into meaningful business insights for better decision-making.
